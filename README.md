# RepoLens

**Structural Grounding for LLM-Assisted Code Comprehension**

RepoLens is a structural ingestion pipeline and visualization tool designed to solve Large Language Model (LLM) hallucinations in software architecture analysis. By parsing raw source code into Abstract Syntax Trees (ASTs) and deterministic dependency graphs, RepoLens provides verified structural facts to LLMs, ensuring highly accurate, hallucination-free codebase documentation.

## Features

* **AST Ingestion Engine:** Utilizes `tree-sitter` to parse repository files and extract exact structural hierarchies (classes, methods, functions) without relying on heuristic text matching.
* **Deterministic Dependency Mapping:** Builds a global directed dependency graph using `NetworkX` to compute centrality, trace inheritance, and identify core modules and system entry points.
* **GraphRAG LLM Grounding:** Prompts LLMs with verified topological subgraphs instead of raw text, drastically reducing context loss and hallucination rates.
* **Post-Generation Verification:** Automatically cross-references every concrete identifier or file path generated by the LLM against the dependency graph to flag unverified claims.
* **Interactive Developer UI:** A React and Vite frontend featuring an Architecture Overview and Dependency Graph explorer to help developers visually navigate complex enterprise systems.

## Tech Stack

* **Backend:** Python, FastAPI, tree-sitter, NetworkX
* **Frontend:** React, TypeScript, Vite, Tailwind CSS
* **Database:** PostgreSQL (with asyncpg)
* **AI/LLM Integration:** Support for Anthropic, Google Gemini, OpenRouter, and local Ollama models
* **Infrastructure:** Docker and Docker Compose

## Getting Started

### Prerequisites
* Docker and Docker Compose
* A GitHub Personal Access Token (prevents rate-limiting during repository cloning)
* An API key for your preferred LLM provider

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/repolens.git
   cd repolens
   ```

2. **Configure environment variables:**
   Create a `.env` file in the root directory:
   ```env
   POSTGRES_PASSWORD=your_secure_password
   GITHUB_TOKEN=your_github_personal_access_token
   CLONE_DIR=/tmp/repos
   ANTHROPIC_API_KEY=your_anthropic_key # Optional
   GOOGLE_API_KEY=your_google_key       # Optional
   OLLAMA_BASE_URL=http://ollama:11434  # For local models
   ```
   *Note: `CLONE_DIR` serves as the temporary staging area where repositories are downloaded before the `tree-sitter` parser analyzes them.*

3. **Launch the application:**
   ```bash
   docker compose up -d --build
   ```
   *The `init.sql` script will automatically configure the PostgreSQL database schema on the first run.*

4. **Access the application:**
   * Frontend UI: `http://localhost:5173`
   * Backend API Docs: `http://localhost:8010/docs`

## System Architecture

1. **Ingestion:** The user submits a GitHub URL. The backend clones the repository into the local `CLONE_DIR`.
2. **Parsing:** The `ast_parser` module analyzes the codebase and stores file-level structural facts in PostgreSQL.
3. **Graphing:** The `dependency_graph` builder maps imports and cross-file relationships.
4. **Generation:** The `insight_engine` queries the graph and prompts the LLM to generate verified architectural documentation.
